# Mini LMS (Student Portal)

A lightweight, professional front-end prototype of a university Student Portal built using only HTML5 and CSS3.

## Project Structure

Mini-LMS/

- index.html
- login.html
- dashboard.html
- profile.html
- courses.html
- attendance.html
- assignments.html
- results.html
- announcements.html
- css/style.css
- images/ (SVG placeholders)
- README.md

## Features

- Login page with Student ID and password fields
- Dashboard with sidebar, topbar, statistics cards, and recent announcements
- Student profile page with personal and academic information
- Responsive course cards
- Attendance table
- Assignment cards with status badges
- Results page with semester table and GPA summary
- Announcements list
- Modern blue & white theme, responsive layout, and accessible HTML structure

## How to run locally (VS Code Live Server)

1. Install the **Live Server** extension in VS Code.
2. Open the project folder `Mini-LMS` in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**.
4. The project should open at either:

```
http://127.0.0.1:5500/
```

or

```
http://localhost:5500/
```

If Live Server uses a different port, it will show the correct URL in the browser.

## Notes

- This is a static frontend only; no backend authentication or data persistence is included.
- All pages are static and interlinked for demonstration purposes.
- Replace the placeholder SVGs in the `images/` folder with official assets when available.
